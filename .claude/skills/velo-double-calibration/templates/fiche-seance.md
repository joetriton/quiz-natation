## 🎚️ Pilotage double calibration
- **Ancre n°1 = puissance** : tiens les watts cibles indoor.
- **Ancre n°2 = RPE** : si à la puissance cible ton RPE dépasse le haut de la
  fourchette → **baisse les watts** pour revenir dans la fourchette RPE (jour sans,
  chaleur, fatigue, FTP datée).
- **RPE trop facile** plusieurs fois sur les blocs durs → ta FTP est sans doute
  sous-estimée : pense à re-tester.
- **En extérieur** : la puissance fluctue, le **RPE devient l'arbitre** ; vise la
  puissance moyenne du bloc.
