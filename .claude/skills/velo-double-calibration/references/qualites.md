# Taxonomie des qualités développées

Codes utilisés par le générateur et le catalogue.

| Code | Qualité | Filière physiologique |
|------|---------|-----------------------|
| RECUP | Récupération / régénération | Régénération |
| ENDUR | Endurance aérobie fondamentale | Aérobie I (Z2) |
| LIPOX | Métabolisme lipidique (fat-max, oxydation des graisses) | Aérobie lipidique |
| DURAB | Durabilité / résistance à la fatigue (tenue de puissance) | Aérobie / fatigue |
| VELO | Vélocité & coordination neuromusculaire (cadence, fluidité) | Neuromusculaire (coordination) |
| TEMPO | Endurance soutenue sous-seuil (capacité aérobie / tempo) | Aérobie II (Z3) |
| SS | Charge aérobie optimisée (sweet spot) | Sweet spot (Z3-Z4) |
| SEUIL | Puissance au seuil (FTP / seuil lactique) | Seuil (Z4) |
| VO2 | Consommation maximale d'oxygène (PMA / VO2max) | Aérobie max (Z5) |
| TOLLAC | Tolérance lactique / capacité à répéter l'effort | Z5-Z6 (répétition) |
| ANA | Capacité anaérobie (production lactique) | Anaérobie (Z6) |
| FORCE | Force spécifique / recrutement musculaire | Force (Z3-Z4 basse cadence) |
| FENDUR | Force-endurance (force tenue dans la durée) | Force-endurance |
| FMAX | Force maximale (couple, basse cadence forte résistance) | Force max (couple) |
| SPRINT | Puissance neuromusculaire / explosivité (sprint) | Neuromusculaire (Z7) |
| SPEC | Spécifique course (allure cible, gestion d'effort, nutrition) | Spécifique course |
