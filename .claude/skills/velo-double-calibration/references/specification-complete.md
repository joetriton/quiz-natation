# Spécification complète des séances (60 séances)

Toute la bibliothèque, **bloc par bloc**, pour implémentation manuelle dans
le constructeur Nolio. Puissances : **%FTP universel** + watts pour la FTP de
référence **228 W** (recalculer : `watts = %FTP × FTP/100`).

Notation : `N× ( effort // récup )` = N répétitions. Chaque ligne donne
durée · cible %FTP (W) · cadence · consigne (zone + RPE).

> Généré par `scripts/generate_bank.py` — ne pas éditer à la main.
